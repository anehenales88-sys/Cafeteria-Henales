# Cafetería Henales

## Descripción
Proyecto web de una cafetería realizado para practicar Git y GitHub.

## Archivos
- `cafeteriaHenales.html`: página web de la cafetería.

## Instalación
1. Descargar o clonar el repositorio.
2. Abrir el archivo `cafeteriaHenales.html` en un navegador web.
